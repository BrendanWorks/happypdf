Privacy Policy

Last updated: July 15, 2026

happypdf (happypdf.org) is an individual, independently-operated project run by Brendan. This policy describes what happens to your data when you use the site. There is no account system, everything below applies per-visit, anonymously.

What happens to a PDF you upload

  • The file is read into memory on a Modal compute container, written to a temporary local file for processing, and deleted immediately after text/structure extraction completes. The raw PDF is never written to permanent storage and is not kept after your job finishes.
  • Extraction (turning the PDF into structured text) runs on a self-hosted model we operate on Modal's GPU infrastructure; the file itself is not sent to any third-party AI provider.
  • The extracted text and generated HTML, not the original PDF file, is sent to one or more third-party AI providers (listed below) so they can review and improve the document's accessibility. This is the only way document content leaves our infrastructure.
  • The job's results (the accessibility report and the generated HTML) are held for 24 hours so you can retrieve them, then automatically and permanently deleted.

If you bring your own API key (BYOK)

  • A key you enter is held only in your browser's page memory (never written to local storage or cookies) and sent once, over HTTPS, to authorize that single job.
  • Your key is never written to disk, never logged, and never stored in our job records. It exists only for the duration of the request that uses it.

Third parties who process document content

These services receive the extracted text/HTML of your document (not the original PDF file) in order to review or improve its accessibility:

ProviderRole
OpenAIAccessibility review (GPT-4o mini), or your own key if supplied
GoogleAccessibility review (Gemini 2.5 Flash)
AnthropicAccessibility review/judging (Claude), or your own key if supplied
ModalCompute hosting for extraction, review orchestration, and temporary job storage
NetlifyHosting for this website

Each provider processes this content under its own privacy policy and terms; we don't control how long they may internally retain API requests under their own policies.

Analytics

We use Google Analytics (GA4) to understand aggregate site usage, page views and a small set of product events (upload started, remediation succeeded/failed, a rough file-size bucket, which AI provider you chose for BYOK). We never send file names, file contents, extracted text, or API keys to analytics. Analytics only loads after you accept the cookie banner shown on your first visit; you can change your choice at any time via the "Cookie preferences" link in the site footer.

Rate limiting

The site enforces a shared daily processing limit to control cost. This limit is a single global counter; it is not tied to your IP address, a cookie, or any identifier, so we don't build any profile of your usage.

What we don't do

  • No accounts, no login, no persistent user identifiers.
  • No selling or sharing of data with data brokers or advertisers.
  • No retention of your document beyond the 24-hour job window described above.

Your choices

  • Decline analytics cookies at any time via the footer link.
  • Use the self-hosted / Docker deployment path (see the GitHub repo) if you'd prefer to run happypdf entirely on your own infrastructure with no third-party calls other than the AI providers you configure yourself.
